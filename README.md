# Bitcoin Scalping Bot

Учебная панель для наблюдения за BTC/USDT и виртуальной проверки сигналов. Реальные ордера не отправляются.

## Структура проекта

- `index.html` — каркас страницы и подключение модулей.
- `css/style.css` — оформление и адаптация интерфейса под телефон/компьютер.
- `js/app.js` — запуск приложения и связь модулей.
- `js/config.js` — общие настройки (порог совпадений, API, журнал).
- `js/chart.js` — отображение графика.
- `js/indicators.js` — расчёт общих индикаторов.
- `js/signals.js` — объединение результатов стратегий; порог сейчас 4 совпадения.
- `js/journal.js` — виртуальные сделки и локальное хранение журнала.
- `data/market.js` — загрузка свечей и поток котировок.
- `strategies/` — каждая стратегия в отдельном файле; список подключаемых стратегий находится в `strategies/index.js`.

## Как добавлять стратегию

1. Создать отдельный файл в `strategies/`, который экспортирует функцию с результатом `BUY`, `SELL` или `WAIT`.
2. Импортировать её и добавить в массив `strategies` в `strategies/index.js`.
3. Добавить название в массив `names` в том же файле.

График, журнал и интерфейс при этом не нужно переписывать.

## Текущие ограничения прототипа

- Рыночные данные: публичный Binance API и WebSocket, инструмент BTCUSDT.
- Журнал хранится в localStorage текущего браузера и не синхронизируется между устройствами.
- Все сделки виртуальные. Не добавляйте биржевые ключи: они не нужны для текущего режима.
- Некоторые стратегии пока упрощённые: VWAP использует среднюю цену как приближение, Stochastic использует RSI-порог, Supertrend использует упрощённое условие относительно EMA21. Перед использованием для серьёзного тестирования их нужно реализовать по точным формулам и отдельно проверить.
- Сигналы и уровни SL/TP являются экспериментальными, не финансовой рекомендацией.

## Публикация

Проект — статический сайт. Для Cloudflare Pages выберите GitHub-репозиторий, ветку `main`, preset `None`, оставьте build command пустой и укажите корень проекта как output directory (`/` или `.`, в зависимости от интерфейса Cloudflare).
